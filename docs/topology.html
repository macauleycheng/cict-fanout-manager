活躍邏輯路徑（VLAN 隔離）
紅色活躍路徑讀法（由上而下）： ixia-1/1 → Spine:p37 → Spine:p1 → Agg-1:up → Agg-1:p3 → Leaf-1-1:up → Leaf-1-1:p5 → DUT-A1:Eth0
這條路徑經過的每一段 Spine↔Agg、Agg↔Leaf trunk 都會被配上同一個 VLAN（例如 VLAN 101）； 其他同時活躍的路徑若共用某段 trunk，就配不同 VLAN 做軟隔離；若想佔用同一實體 port 則為硬衝突，分配失敗。

關鍵設計意圖
1. Leaf→DUT 線固定：接一次就不動，拓樸檔穩定。
2. 掛載彈性在 Agg↔Spine 用 VLAN 控制：換 rack 不需重插線，由系統下發 fanout VLAN。
3. 一次最多 12 條活躍路徑（generator 上限），故上層不會壅塞；衝突管理聚焦在共用 trunk 的 VLAN 隔離。
4. 重開機偵測：系統須檢查 fanout 是否重啟（設定遺失），若是則重新下發當前活躍 VLAN。
